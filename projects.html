Research Projects in Network Security and Intelligent Threat Detection

A selection of research projects exploring the detection, analysis and mitigation of denial-of-service attacks in Software-Defined Networks (SDN). The work combines experimental network environments, statistical analysis and machine learning to investigate how network behaviour can be used to identify attacks and strengthen infrastructure resilience.

PROJECT 01

Machine Learning-Based Detection and Classification of DDoS Flooding Attacks in Software-Defined Networks

Journal article | IEEE Access | 2021

Software-Defined Networking offers programmability and centralised network management, but its architecture also creates security challenges. Distributed Denial of Service (DDoS) flooding attacks can consume network resources and undermine service availability. This project investigated how machine learning could distinguish malicious flooding activity from legitimate network behaviour in an SDN environment.

Research approach

An experimental SDN environment was used to generate and examine network traffic under normal conditions and during HTTP, TCP and UDP flooding attacks. Network performance indicators, including throughput, jitter and response time, were used to develop and evaluate machine learning classifiers, including Quadratic Discriminant Analysis, Gaussian Naïve Bayes, k-Nearest Neighbour and Classification and Regression Tree (CART).

Contribution

The study demonstrated the potential of data-driven classification for identifying DDoS flooding activity in programmable networks. CART achieved the strongest overall reported classification performance, with an average prediction accuracy of 98%. The findings illustrate how experimentally generated network data can support the development and evaluation of intelligent network threat-detection approaches.

PROJECT 02

Statistical Anomaly Detection of DDoS Attacks in Software-Defined Networks

Conference paper | IEEE FiCloud | 2018

Detecting DDoS attacks is challenging because malicious traffic can share characteristics with legitimate network activity. This project explored a statistical approach to identifying abnormal traffic behaviour in SDN environments, with particular attention to flooding attacks that affect the availability of network services.

Research approach

The work used an emulated SDN environment to investigate TCP-ACK, SYN and Slowloris attacks. Throughput measurements gathered from the victim server were used to establish a statistical baseline. The detection approach examined deviations from the baseline to identify abnormal behaviour and assess attack severity.

Contribution

The study presented a lightweight, measurement-led approach to DDoS detection that uses performance information collected at the victim server. It also considered how data collection could reduce the need for extensive communication between the controller and network switches. The work highlights the value of statistical baselining as a practical technique for network anomaly detection.

PROJECT 03

Assessing the Impact of Denial-of-Service Attacks on Software-Defined Networks

Conference paper | WiSATS 2017 proceedings | Published 2018

SDN separates network control functions from data forwarding, creating flexibility but also introducing security considerations. This project examined how a Denial of Service (DoS) attack can affect network performance and the availability of services in an SDN environment.

Research approach

An experimental network was constructed using Mininet and the OpenDaylight (ODL) controller. Network performance was evaluated using tools including iperf and ping. ICMP flooding was performed against TCP and UDP servers connected through OpenFlow switches, allowing the impact on throughput and jitter to be observed.

Contribution

The experiments showed a substantial reduction in throughput, from 233 Mbps to 87.4 Mbps, together with increased jitter during the attack. The findings provide an empirical illustration of how DoS activity can degrade SDN performance and reinforce the importance of evaluating availability and resilience as part of network security design.

PROJECT 04

A Framework for DDoS Attack Detection and Reactive Countermeasures in Software-Defined Networks

Conference paper | IEEE FiCloud | 2019

Detection is an important part of network defence, but identifying an attack is only one element of an effective response. This project extended the research focus from attack detection towards a framework that considers both the identification of DDoS activity and reactive countermeasures in an SDN environment.

Research focus

The work addresses the use of SDN architecture for DDoS attack detection and response. By considering the network's programmable control capabilities, the research investigates a framework-oriented approach to detecting malicious activity and triggering responsive countermeasures.

Contribution

The project contributes to the broader investigation of security mechanisms for programmable networks, connecting attack detection with the need for timely response. It forms part of a progression from measuring attack impact and identifying anomalous behaviour towards considering how SDN environments can support reactive defence.

PROJECT 05

Sensitivity Analysis of Software-Defined Network Performance Parameters for DDoS Detection

Journal article | Simulation Modelling Practice and Theory | 2020

Effective anomaly detection depends on selecting network indicators that provide meaningful evidence of abnormal behaviour. This project investigated the sensitivity of key SDN performance parameters to DDoS flooding attacks, helping to understand which measurements may be most informative for network monitoring and detection.

Research approach

The study applied Local Sensitivity Analysis (LSA) and an Artificial Neural Network (ANN)-based prediction model to examine throughput, jitter and response time. Additive White Gaussian Noise (AWGN) was introduced to assess the sensitivity of the model outputs by examining deviations between predicted and actual values.

Contribution

The findings indicated that all three performance metrics were sensitive to DDoS flooding attacks, with jitter identified as the most sensitive indicator. This provides useful insight for selecting and prioritising network features in monitoring and intelligent detection models.
