CYBERSECURITY & INFORMATION SECURITY

Professional certifications

Credentials supporting a broad understanding of information security management, security architecture, risk management and the protection of cloud environments.

CISSP

Certified Information Systems Security Professional (CISSP)

(ISC2) | Issued March 2022

An internationally recognised information security certification covering the design, implementation and management of an organisation's security programme. Its domains span security and risk management, asset security, security architecture and engineering, communications and network security, identity and access management, security assessment and testing, security operations, and software development security.

Professional relevance: Information security leadership, security governance, enterprise risk, security architecture, control assurance and security operations.

View digital credentials on Credly

CCSP

Certified Cloud Security Professional (CCSP)

(ISC2) | Issued July 2022

A specialist cloud security certification addressing the knowledge required to design, manage and secure cloud environments. It covers cloud concepts, architecture and design, cloud data security, cloud platform and infrastructure security, cloud application security, and cloud security operations, alongside legal, risk and compliance considerations.

Professional relevance: Cloud security governance, secure cloud architecture, cloud risk management, data protection, infrastructure security and compliance.
